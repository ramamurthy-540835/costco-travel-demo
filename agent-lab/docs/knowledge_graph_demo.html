Shared Vocabulary, Two Sides of the Market

This graph is the single source of truth both members and vendors resolve natural-language phrasing against — the same synonym-property pattern serves a member typing “pick up in Vegas” and a fulfillment-side agent matching cross-vendor VehicleClass naming variance. Most of this vocabulary is hand-curated (Phase 2); Location.synonyms is the first slice generated by a real LLM call (Phase 7) rather than a hardcoded dict, via graph/scripts/backfill_synonyms.py.
