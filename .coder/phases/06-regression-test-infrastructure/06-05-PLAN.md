## AC-1: Adding a fee-bearing addon charges the correct delta
```gherkin
Given a reserved booking with no addons yet
When the test adds a fee-bearing addon (e.g. Roadside Assistance) via the mocked delta-payment flow
Then the booking's pricingSnapshot.addonTotal increases by fee_per_day × nights, matching a live getAddOnsCatalog() read
```

## AC-2: A perk-waived addon is shown locked at $0 and cannot be double-charged
```gherkin
Given a reserved booking whose member perks waive a specific addon (per getWaivedAddOnIds())
When the test opens the addons dialog
Then that addon renders checked, disabled, and waived-at-$0 (read the real rendered copy from booking-addons-form.tsx — do not assume specific wording), and attempting to submit it as a paid addon via a direct API call is rejected or ignored server-side (no charge recorded)
```

