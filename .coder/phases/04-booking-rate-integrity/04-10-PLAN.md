<objective>
## Goal
Fix three live-rendering gaps surfaced by the user on the real (non-prototype) discovery flow — (1) "Browse by vehicle type" only shows 3 of 9 classes per page, (2) every result within a vehicle class shows the same single make/model with a repeated stock photo, (3) the vendor marquee is visually flat — and add a checked-in Playwright smoke suite so future regressions are caught automatically instead of via ad hoc screenshots.

## Purpose
04-09 shipped the hero/header/carousel/marquee/landing rework. This plan is a follow-up fix pass on that same surface: the carousel's pagination and the seed data's 1:1 class→make/model mapping were both there before 04-09 but only surfaced once the user looked closely at live rendering. Root-caused during planning (Explore agents): carousel gap is `PAGE_SIZE = 3` in `components/vehicle-type-carousel.tsx`; make/model gap is the raw seed file `data/reference/mock-data/rental_inventory.json` hardcoding one (make, model) pair per class across all rows (confirmed via direct inspection — not a query bug in `lib/graph/queries.ts`'s `searchInventory`).

## Output
- Ontology docs (`VOCABULARY.md`, `ONTOLOGY.md`) updated to document that `Inventory.vehicle_make`/`vehicle_model` is now a 1-to-3 relationship per `VehicleClass`, not 1:1.
- `data/reference/mock-data/rental_inventory.json` rewritten (via new one-off `scripts/reassign-vehicle-makes.mjs`) so each of the 9 canonical classes has 3 distinct (make, model) pairs, deterministically assigned by `rental_id` hash; graph reloaded via `graph/scripts/load_seed_data.py`.
- `lib/vehicle-images.ts` gains a `VEHICLE_IMAGE_MAP` keyed by `"${make} ${model}"` with 18 newly-verified Wikimedia Commons images (2 new makes × 9 classes); `components/vehicle-card.tsx`'s `CardImage` looks up make/model first, falling back to the existing class-level `CLASS_IMAGE_MAP`, falling back to the icon.
- `components/vehicle-type-carousel.tsx`: `PAGE_SIZE` 3 → 6.
- `components/vendor-marquee.tsx`: brand-color accent bar, hover lift, edge fade mask — pure CSS/Tailwind, no new deps.
- `@playwright/test` devDependency, `playwright.config.ts`, `tests/e2e/smoke.spec.ts` (checked into the repo, replacing the ad hoc `/tmp/pwtest` pattern), `"test:e2e"` npm script.
</objective>
