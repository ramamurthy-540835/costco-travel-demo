<objective>
## Goal
Expand 04-06's real-data landing page with 4 additions the user requested mid-checkpoint: (1) a full multi-field search form in the hero (location + dates + vehicle class, not just location), (2) a global site header with Clerk sign-in/sign-up, (3) a "Browse by vehicle type" image carousel (more than 3 classes, real images), (4) a "Our rental partners" moving marquee.

## Purpose
04-06 shipped a minimal-but-real landing page (Tasks 1-3 executed and qualified PASS) and reached its human-verify checkpoint. Instead of approving, the user asked for 4 concrete UI upgrades, explicitly instructing this be handled as a new plan ("expand the current plan... use coder plan") rather than a checkpoint fix — because none of these are defects in what 04-06 built; they're new scope. 04-06's checkpoint is treated as superseded by this plan, not separately resolved.

- `app/landing-hero.tsx`: hero search form replaced with a full client-side form (location, pickup/return dates, vehicle class) submitting to `/search` with all params.
- `components/header.tsx` (new) + `app/layout.tsx`: global nav with Clerk `<SignedIn>`/`<SignedOut>` controls, rendered on every page.
