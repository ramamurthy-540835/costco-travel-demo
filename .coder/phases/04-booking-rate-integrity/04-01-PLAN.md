<objective>
## Goal
Re-theme the shadcn/base-ui design tokens in `app/globals.css` so the `/prototype/*` screens visually approximate BookCars' MUI look (colors, corner radius, spacing feel) while keeping the same shadcn component code — no component code changes, token values only.

## Purpose
User explicitly chose (via AskUserQuestion, this session) to replicate BookCars' MUI visual style, not just its flow/IA, as part of "as close to BookCars as possible." This is the visual-fidelity half of that decision.

## Output
Updated `:root` / `.dark` oklch color tokens and `--radius` value in `app/globals.css`, applied automatically across all `/prototype/*` screens with zero component-file edits.
</objective>
