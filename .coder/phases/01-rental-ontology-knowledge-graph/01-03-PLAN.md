# 01-03 — Vendor Expansion & BookCars-Aligned Enrichment

## Context
User request: add more vendors (Hertz, Thrifty, etc.), take further reference from BookCars, and enhance the dataset/knowledge graph. Confirmed scope via clarifying questions: 5 new vendors, inventory scaled proportionally, new BookCars-aligned fields on Vendor and Inventory. Executed in one pass (plan + apply) rather than a separate PLAN→APPLY split, since the scope was small and fully clarified up front.

## Scope
1. Add 5 vendors — Hertz, Thrifty, Dollar, Sixt, Payless — → 10 total.
2. Backfill/add `minimum_rental_days`, `price_change_rate` on all 10 `Vendor` rows (BookCars `SupplierForm.ts`-aligned).
3. Grow `Inventory` proportionally: 500 existing + 500 new (100/vendor for the 5 new vendors) = 1000 rows. Enrich all 1000 with `vehicle_type` (fuel), `gearbox`, `seats` (BookCars `Car.ts`-aligned).
4. Add 15 `NegotiatedTerm` rows (5 vendors × 3 tiers, `nt_016`–`nt_030`) and 5 `VendorPolicy` rows, matching existing field shapes exactly.
5. Real thesaurus exercise: Sixt's `included_miles` = `"300 mi/day"` (not Unlimited); Payless uses `"Compact Plus"` as a raw `vehicle_class` alias of canonical `Compact` on part of its inventory — converts `VocabularyTerm`/`SYNONYM_OF` from documented-zero to real seeded data.
6. Rename `rental_inventory_500.json` → `rental_inventory.json` (row count outgrew the filename).
7. Update `graph/scripts/load_seed_data.py` (alias resolution, `VocabularyTerm`/`SYNONYM_OF` seeding) and `verify_graph.py` (new expected counts, drop the `SYNONYM_OF` zero-exception).
8. Update `VOCABULARY.md`, `TAXONOMY.md`, `THESAURUS.md`, `ONTOLOGY.md` to reflect the above.

**Not in scope:** `bookings_1000.json`/`members_100.json` — new vendors get inventory/terms/policies but no reservations yet (deferred to Phase 3). No graph schema changes (vlabels/elabels unchanged).

## Acceptance criteria
- `python graph/scripts/load_seed_data.py` run twice → identical counts (idempotent)
- `python graph/scripts/verify_graph.py` → all label counts match new expected values, all 16 edge types present (including `SYNONYM_OF` for real), all identity lookups pass
- No sibling project (`mastech-agentic-commerce`, `mastech-rental-car-management`) modified — read-only reference only

## Reference used (read-only)
- `mastech-rental-car-management/backend/src/models/Car.ts` — `CarType` (fuel), `GearboxType`, seats fields
- `mastech-rental-car-management/admin/src/models/SupplierForm.ts` — `minimumRentalDays`, `priceChangeRate` fields
