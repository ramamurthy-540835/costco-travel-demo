<objective>
## Goal
Define the three enrichment layers that sit beneath the existing Ontology/Knowledge-Graph design (`ONTOLOGY.md`, `graph_schema.sql`) — Vocabulary (canonical term list), Taxonomy (hierarchical structure over VehicleClass and MembershipTier), and Thesaurus (cross-vendor synonym/alias mapping) — mirroring the five-layer model (Vocabulary/Taxonomy/Thesaurus/Ontology/Knowledge Graph) used in `mastech-agentic-commerce` Phase 5, and extend `graph_schema.sql` + `ONTOLOGY.md` so these layers are represented as real graph structure, not prose-only documentation.

## Purpose
Rental data crosses 5 independent vendors (Alamo, Avis, Budget, Enterprise, National) whose raw terminology for the same concept varies (vehicle class names, mileage-inclusion phrasing) or needs explicit rank ordering (membership tiers, cancellation windows). Without a Vocabulary/Taxonomy/Thesaurus layer, Discovery/Checkout and billing-dispute resolution (UC1/UC2/UC3/UC6) would each have to re-derive "these two vendor terms mean the same negotiated benefit" ad hoc. This plan makes that resolution a queryable graph structure that Phase 3 (booking) and Phase 4 (add-on integrity) consume directly, the same way agentic-commerce's thesaurus/taxonomy layer fed its `search_products` recall.

## Output
- `VOCABULARY.md` — canonical term list for every name-valued property across the 11 ontology node types, sourced from `data/reference/mock-data/*.json` and `data/synthetic/*.json`
- `TAXONOMY.md` — hierarchical structure for `VehicleClass` (parent/child grouping) and `MembershipTier` (strict rank order), expressed as graph relations
- `THESAURUS.md` — synonym/alias mapping for vendor-specific terminology (vehicle class naming variance, mileage-inclusion phrasing, perk naming variance)
- `graph_schema.sql` extended with `VocabularyTerm` node label, `PARENT_OF` (taxonomy) and `SYNONYM_OF` (thesaurus) edge labels, plus the vlabel/elabel `SELECT create_*` statements for them
- `ONTOLOGY.md` updated with a "Vocabulary/Taxonomy/Thesaurus" section cross-referencing the three new docs and the new graph structure
</objective>
